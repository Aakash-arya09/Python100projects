## 📌 About This Repository

This repository contains my complete learning journey through the **Python Mastery: 100 Days, 100 Projects** course on Udemy.

The purpose of this repository is not just to finish a Python course. It is to **learn Python by building practical projects**, improve problem-solving skills, understand how real applications are structured, and create a portfolio of work on GitHub.

The course progresses from Python fundamentals to:

- 🐍 Python programming

# 📝 My Daily Workflow

For every project, I will follow this process:

### 1. 📚 Learn
Understand the concept taught in the day's lesson.

### 2. 💻 Code
Write the project myself and avoid blindly copying.

### 3. 🧠 Understand
Explain to myself what each important part of the program does.

### 4. 🐛 Debug
Find errors, understand why they happen, and fix them.

### 5. 🔧 Improve
Add extra features or improve the user experience whenever possible.

### 6. 📝 Document
Write useful notes and a short project description.

### 7. 🚀 Commit
Push the finished project to GitHub.
