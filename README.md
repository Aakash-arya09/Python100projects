# 🐍 Python Mastery: 100 Days, 100 Real-World Projects

> **A 100-day journey to learn Python by building 100 practical projects — from beginner fundamentals to advanced concepts.**

This repository contains my progress, notes, code, and projects while completing the **Python Mastery: 100 Days, 100 Projects** course.

The goal is simple: **learn Python by building instead of only watching tutorials.**

---

## 🎯 Challenge Goal

I am following a **100 Days → 100 Projects** learning approach.

Each day, I aim to:

- 📚 Learn a new Python concept
- 💻 Write and understand the code myself
- 🛠️ Build a practical project
- 📝 Save my work in this repository
- 🚀 Improve the project whenever possible
- 🔁 Practice concepts from previous days

By the end of the challenge, I want to have a portfolio containing **100 Python projects**.
